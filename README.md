# Student CRUD Application

A full-stack Student CRUD application built with React, FastAPI, and PostgreSQL.

## Features

- Add students
- View all students
- Edit student information
- Delete students
- Search students
- Pagination
- Toast notifications
- Loading states
- Responsive dashboard interface

## Tech Stack

### Frontend

- React
- Vite
- Axios
- React Hot Toast

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL
- Uvicorn
